# freeCodeCamp-beDevAndApi-timestampMicroservice
Node.js project: [Build a Timestamp Microservice](https://www.freecodecamp.org/learn/back-end-development-and-apis-v9/lab-timestamp-microservice/lab-timestamp-microservice),  
part of the  [freeCodeCamp Back-End Development and APIs Certification (Version 9)](https://www.freecodecamp.org/learn/back-end-development-and-apis-v9/).

## Examples
The following endpoints demonstrate the API:
- `http://localhost:8000/api/2025-01-31` – Date string
- `http://localhost:8000/api/1451001600000` – Unix timestamp
- `http://localhost:8000/api` – Current date and time
- `http://localhost:8000/api/test` – Invalid date
